# appearance-llava

대회 사진에서 참가자의 옷차림을 읽어내는 프로그램이다.

> 2024년 작업이다. [픽마이레이스(PickMyRace)](https://github.com/sprtms400/Granfondo_Photo_Search)에서 인상착의를 뽑아내는 부분을 맡는다.

---

# 개요

## 1. 어떤 문제를 해결하려 했나요?

대회 사진에서 사람을 찾는 표준적인 방법은 배번호를 읽는 것이다. 그런데 배번표가 안 보이는 사진이 많다. 뒤나 옆에서 찍혔거나, 몸이 가렸거나, 흐릿하거나.

이런 사진들은 배번호로는 영영 주인을 못 찾는다. 그래도 사람은 자기 사진을 알아본다. "나 그날 노란 상의에 빨간 자전거였는데" 로 기억하기 때문이다.

## 2. 어떻게 되었나요

사진을 보고 답하는 모델(LLaVA)에게 옷차림을 물어보게 했다. 여덟 가지를 읽어낸다.

1. 성별
2. 헬멧 착용 여부와 색상
3. 고글 또는 선글라스 착용 여부와 색상
4. 상의 긴팔·반팔 여부와 색상
5. 하의 긴바지·반바지 여부와 색상
6. 양말 착용 여부와 색상
7. 신발 색상
8. 자전거 탑승 여부와 색상

이 정보가 붙으면 배번표가 안 보이는 사진도 검색된다.

## 3. 향후 과제

읽어낸 색이 얼마나 맞는지 재본 적이 없다. 조명이나 그림자에 따라 같은 옷이 다른 색으로 읽힐 수 있다.

# 상세

## 1. 기존 문제 설정

**모델이 자유롭게 답한다.** 이미지를 보고 답하는 모델에게 "이 사람 뭐 입었어?" 라고 물으면 문장으로 대답한다. "노란색 저지를 입고 있으며 검은 반바지를 착용한 것으로 보입니다" 같은 식이다. 이걸 그대로 데이터베이스에 넣을 수는 없다.

**항목을 빠뜨린다.** 한꺼번에 여덟 가지를 물으면 몇 개는 답하지 않거나 뭉뚱그린다.

**따로 학습시킬 데이터가 없다.** 옷차림 분류 모델을 직접 만들려면 라벨이 붙은 대회 사진이 수만 장 필요하다. 없다.

## 2. 해결방안 제시

**답의 형식을 예시로 가르친다.** 원하는 출력 형태를 몇 개 보여주고 그대로 흉내내게 한다. 모델을 다시 학습시키지 않고 프롬프트만으로 형식을 고정하는 방법이다.

**항목별로 나눠 묻는다.** 여덟 가지를 한 번에 묻지 않고 항목마다 따로 묻는다. 빠뜨림이 줄어든다.

**모델은 직접 띄운다.** 대회 사진은 참가자 얼굴이 그대로 담긴 개인정보다. 외부 서비스에 올리지 않고 자체 서버에 LLaVA 를 띄워 처리한다.

## 3. 구현 상세

### 처리 순서

```
대회 사진
  → 항목별 질문을 만들어 붙임        (restful_interface/prompt_combinator.py)
  → 자체 서버의 LLaVA 에 요청        (restful_interface/comunicator.py)
  → 답을 정해진 형식으로 파싱        (utils/parser.py)
  → 색상 정보 업로드                 (utils/color_uploader.py)
```

### 전체 시스템에서의 위치

녹색 상자가 이 저장소가 맡은 부분이다.

![담당 범위](https://github.com/sprtms400/appearance-llava/assets/26298389/1151f74e-3c5d-411c-94de-1971e19c5000)

### 구성

| 파일 | 하는 일 |
|---|---|
| `restful_interface/prompt_combinator.py` | 항목별 질문 조립 |
| `restful_interface/comunicator.py` | LLaVA 서버와 통신 |
| `utils/parser.py` | 모델 답변을 형식에 맞게 파싱 |
| `utils/description_generator.py` | 읽어낸 정보로 설명 문장 생성 |
| `utils/color_uploader.py` | 색상 정보 업로드 |
| `config/zeroshot_template.json` | 모델에게 줄 질문 형식 |

### 준비물

Ubuntu 20.04, Python 3.10.

돌리기 전에 LLaVA 서비스가 떠 있어야 한다.

- 모델 — https://huggingface.co/liuhaotian/llava-v1.5-7b
- 구동 방법 — https://github.com/haotian-liu/LLaVA

## 4. 한계점

- 색 인식 정확도를 측정한 기록이 없다. 조명과 그림자에 얼마나 흔들리는지 모른다.
- LLaVA 를 띄울 GPU 서버가 따로 있어야 한다.
- 사진에 여러 명이 찍혔을 때 누구를 기준으로 답하는지가 명확하지 않다.
- 테스트 코드가 없다.
